# EV ChargeHub

MERN-based EV charging station management and analytics dashboard for the MCA mini project.

## Current milestone
- Premium dark dashboard UI matching the approved visual direction
- Responsive layout
- Charging analytics charts
- Charger status visualization
- Pune live-map style prototype area (Leaflet integration comes next)
- Active charging session widget
- Express API starter

## Run frontend
```bash
cd client
npm install
npm run dev
```

## Run backend
```bash
cd server
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5000/api/health
